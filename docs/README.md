# Product documents

## Current direction

- [Eve-backed Agent component v0.1 PRD](convex-eve-agent-v0.1-prd.md) — the
  current product direction: Convex-native threads, messages, UI parts, and
  React helpers backed by agents authored and executed in Eve.

## Retained exploration

- [General control-plane v0.1 PRD](convex-eve-v0.1-prd.md) — the original,
  broader proposal for a general-purpose Convex control plane over every Eve
  session. It remains as design history and a source of protocol and security
  analysis, but is not the current implementation target.
- [ADR 0001](decisions/0001-application-control-plane-and-public-naming.md) —
  the earlier application-control-plane and naming decision. Its useful naming
  conclusions may be carried forward selectively; its product scope is
  superseded by the current PRD.
