## Available now

- Bun and Turborepo monorepo
- Convex component installation
- Scope- and subject-bound application threads
- Pending user messages saved before Eve delivery
- Serialized delivery claims per Eve session generation
- Eve create-once operation IDs for new sessions
- Ambiguous delivery outcomes block retries in the `unknown` state
- Bounded Eve stream catch-up with exponential backoff in the example bridge
- Delivery acceptance only after an Eve session boundary
- Fixed thread-to-Eve-session bindings
- Exact stream-index ingestion and coordinate deduplication
- Eve-native `EveMessage` and reducer semantics
- Sanitized message parts without reasoning or full tool payloads
- Paginated `useUIMessages` React hook
- Native Eve performance coach project
- Marketing, documentation, and example applications

## Next milestone

- Workpool-backed dispatch and reconciliation leases
- Input-response idempotency and recovery
- Snapshot-based projection rebuilds
- Retention, deletion, reset, clear, compact, and cancel APIs
- End-user identity propagation for host-backed tools
- Broader component integration and failure-injection tests

Do not use the current package as a production integration.
